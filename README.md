# ConceptCLIP professor demonstration

Open **index.html** to show the entire demonstration locally. No installation,
login, access code, Python server, database or backend URL is needed.

Choose BrEaST or LUNA16, select any case, and click Image → Scores → Heatmaps.
Try diagnosis, every concept question, confidence, image enlargement and
plain/map toggles. You can advance without answering anything. Answers exist
only temporarily in this page and disappear on reload.

## Share it on GitHub Pages

Upload the contents of this extracted ZIP to the root of:
https://github.com/ConCLIPV2/ConCLIPV2.github.io

Include assets/ and the hidden .github/ folder. In Settings → Pages, choose
GitHub Actions as the source. Push to main or run the workflow named
"Publish clickable professor demo". After deployment succeeds, share:
https://conclipv2.github.io/

No repository secrets, environment variables or backend configuration required.
You may instead use Pages branch deployment from main / root.

All 7 BrEaST and all 6 LUNA16 attributes have scores and annotation questions
at every step. Only the heatmap panel uses the four selected attributes.

The 50 cases, 325 attribute displays and 300 prepared images are intentionally
part of this public presentation. This is a demonstration, not response
collection. It contains no participant answers, credentials, private research
manifest, original filesystem paths or clinical reference labels.
